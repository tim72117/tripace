# 前端可點擊元素行為清單

列出 `web/src` 底下各畫面中「點下去會觸發某個行為」的元素與其行為,供快速查閱某個按鈕/卡片點下去實際會發生什麼事。次要/demo 用途的檔案(`DemoPanel.tsx`、`clienttools/`、`PublicPaceDemoPage.tsx` 等)只簡略帶過。

這份清單是特定時間點的快照,程式碼變動後不會自動同步——若發現條目與實際行為不符,以程式碼為準,並回來更新這份文件。

## HomePage.tsx(首頁,根路徑 /)

- 主視覺「開始探索」按鈕｜捲動到 `#explore` 區塊(頁面內錨點,非導頁)
- 左上品牌標記「Tripace」｜連回 `/`
- 右上日夜間切換鈕｜切換 `data-theme`(dark/light 互切)
- 結尾「規劃我的探索路線」按鈕｜導向 `/app`
- 頁尾「產品功能」連結｜導向 `/product`
- 頁尾「隱私權政策」/「服務條款」連結｜導向 `/privacy`/`/terms`

## ProductPage.tsx(產品功能介紹頁,/product)

- 導覽列「立即開始」按鈕｜導向 `/app`(App 本身內建登入/註冊表單,無獨立
  `/login`、`/register` 頁面)
- 右上日夜間切換鈕｜切換 `data-theme`(dark/light 互切)
- 主視覺「免費開始使用」按鈕｜導向 `/app`
- 結尾「免費開始使用」按鈕｜導向 `/app`
- 頁尾「回首頁」連結｜導向 `/`

## DesktopLayout.tsx(桌面版整體佈局)

- Rail「行程列表」圖示鈕｜切換疊加顯示 `DesktopTripList`(不影響主顯示區)
- Rail「時間軸」圖示鈕｜切到 `timeline` 面板(未選行程時停用)
- Rail「路徑」圖示鈕｜切到 `pace` 面板(配速表)
- Rail「規劃」圖示鈕｜切到 `geo-outline` 面板(地理輪廓底圖)
- Rail(`?demo` 模式限定)試做按鈕群｜切到對應 demo 面板
- Rail(`?demo`)「API / WS 狀態面板」開關鈕｜顯示/隱藏 debug 面板
- 側欄「新增行程」項目｜原地展開輸入框,輸入名稱後按「建立」呼叫建立行程 API
- 側欄既有行程項目｜設為 `activeTrip`,切換到該行程對話畫面
- 使用者選單觸發鈕(頭像＋名稱)｜開關 popover 選單
- Popover「設定」項目｜開啟設定彈窗
- Popover「登出」項目｜呼叫登出
- 設定彈窗「開發」折疊列｜展開/收合開發者資訊(Token、Base URL、健康檢查)
- 設定彈窗「GET /health」列｜呼叫健康檢查 API 並顯示結果
- 語言下拉選單｜切換助理回答語言並存 localStorage

## GeoOutlineMap.tsx(地理輪廓底圖 - 桌面版地圖)

- 地圖上方「景點/飯店/餐廳」類別標籤按鈕｜以地圖中心查詢該類別附近地點,再點一次取消選取並清空結果
- 「搜尋這個區域」浮動按鈕(僅在已選類別標籤、且拖曳/縮放過地圖後才出現)｜以目前地圖中心重新查詢景點區域/飯店,並重新查詢目前選中的類別
- 景點區域光暈疊層(地標圖示)點擊｜放大/查看該地標,並即時查詢附近推薦地點
- 飯店 marker 點擊｜回報選取該飯店(開啟資訊卡、側欄同步標記)
- 附近推薦地點 marker 點擊(依類別標籤查出的三種地點各自對應飯店/景點/餐廳圖示,其餘查詢結果沿用相機圖示)｜回報選取該推薦地點
- 地圖上 Google 原生 POI 圖標點擊｜攔截預設資訊卡,改查詳細資料後開啟自訂資訊面板

## GeoCandidateSidebar.tsx(候選籃側欄)

- 城市搜尋輸入框＋「查看」按鈕｜觸發城市座標查詢並移動地圖
- 候選項目卡片本體｜開啟資訊面板顯示該地點介紹
- 候選項目「×」移除鈕｜從候選籃移除
- 「已排入行程」日層架卡片本體(依日期分組,圖示對應 entry 類型)｜開啟資訊面板(同候選項目)
- 日層架卡片「×」移除鈕｜移除該候選(僅前端狀態,不影響實際行程資料)

## GeoHotelSidebar.tsx(飯店/地點/附近推薦側欄)

- 頂部分頁「地點」「飯店」「附近推薦」圖示鈕｜切換顯示分頁
- 各分頁項目卡片本體｜移動地圖到該座標並標記選取
- 各分頁項目「+」加入候選鈕｜把該項目加入候選籃

## GeoInfoPanel.tsx(浮動地點介紹卡)

- 關閉按鈕(X)｜關閉資訊卡
- 「加入候選」按鈕(僅有候選來源資料時顯示)｜把該地點加入候選籃

## Timeline.tsx(多軌時間軸)

- 主線卡片／子卡片本體點擊｜展開/收合卡片詳細內容
- 卡片內「編輯」按鈕(僅登入使用者)｜開啟編輯表單
- 導航小箭頭圖示連結｜開新分頁前往 Google 地圖導航該地點
- 編輯表單「取消」/「儲存」按鈕｜關閉不儲存 / 呼叫 API 更新條目

## ChatScreen.tsx(對話主畫面)

- Navbar(手機版)左上角按鈕｜開啟導覽抽屜
- Navbar(桌面版)左上角返回箭頭｜返回清空選取行程
- Navbar「⋯」行程選單｜開關「開啟時自動進入」設定
- Navbar「分享」圖示鈕(僅 owner)｜開啟分享彈窗
- Navbar「成員」圖示鈕｜開啟成員管理頁
- 輸入列「推薦附近景點」閃電圖示鈕｜直接送出「推薦附近的景點」訊息
- 輸入列「送出」按鈕｜送出訊息
- 詢問補值面板(agent 詢問缺資訊時彈出)「取消」/「確定」/各選項按鈕｜取消或送出使用者回覆

## MessageBubble.tsx(訊息泡泡與附加資料)

- 「推薦景點/旅程清單」摺疊區塊觸發按鈕｜展開/收合附加資料面板
- 旅程清單表格 checkbox、列本體點擊｜勾選/取消勾選要刪除的項目
- 「刪除(N)」按鈕｜刪除勾選的項目

## PhoneContent.tsx / PhoneNavDrawer.tsx / PhoneTripsDrawer.tsx(手機版導覽)

- 主導覽列「行程列表」按鈕｜開啟導覽抽屜
- 主導覽列「時間軸」/「路徑」圖示鈕｜切換主顯示區模式
- 抽屜「行程列表」觸發鈕｜開啟獨立的行程列表抽屜
- 抽屜分頁列圖示鈕｜切換抽屜內容分頁
- 抽屜右上角「⋯」/「分享」/「成員」/頭像按鈕｜同 ChatScreen 對應功能
- 行程列表抽屜「新增行程」/既有行程項目｜新增或切換行程
- 抽屜左滑手勢｜關閉抽屜

## PaceChart.tsx / PaceRouteMap.tsx(配速表)

- 路線分頁標籤按鈕｜切換顯示不同路段
- 「分享這個路徑」按鈕｜複製固定展示頁連結
- 檢查站卡片點擊｜平移地圖到該座標(無座標時先呼叫後端 geocode 補座標)
- 「回到目前位置」圖示鈕｜地圖平移回使用者目前位置
- 「模擬移動」/「停止模擬」按鈕｜開關沿路線模擬移動的測試功能
- 「導航模式」按鈕｜開關地圖跟隨行進方向旋轉
- 選點圖釘＋「儲存座標」按鈕｜呼叫 API 儲存目前圖釘座標

## SettingsScreen.tsx(手機版設定整頁)

- 返回箭頭｜返回上一頁
- 「登出」列｜呼叫登出
- 「GET /health」列｜呼叫健康檢查 API 並顯示結果
- 語言下拉選單｜切換助理回答語言並存 localStorage

## trip/ShareModal.tsx(分享彈窗)

- 返回箭頭｜關閉彈窗
- 「複製連結」按鈕/圖示鈕｜複製公開連結到剪貼簿
- 「允許訪客新增行程」開關(僅 owner)｜切換公開連結是否可編輯
- 顯示模式分段按鈕(僅 owner)｜切換公開頁呈現方式(時間軸/路徑)
- 「撤銷連結」按鈕(僅 owner)｜刪除目前的公開連結
- 「建立公開連結」按鈕(僅 owner)｜建立新的公開分享連結

## trip/MembersScreen.tsx(成員管理頁)

- 返回箭頭｜返回上一頁
- 成員權限標籤按鈕(僅 owner)｜切換該成員 editor/viewer 權限
- Email 輸入框＋「邀請加入」按鈕｜以 email 邀請新成員

## 次要/demo 用途檔案(簡略)

- `DemoPanel.tsx`:debug 面板的清空紀錄等按鈕
- `clienttools/`:ClientToolsBridge/onagent 串接試做頁的連線/送出按鈕
- `PublicPaceDemoPage.tsx`:固定示範資料頁,互動同 `PaceChart`/`PaceRouteMap`
- `PacePhoneSwipe.tsx`:手機版配速表滑動抽屜,互動同導覽抽屜拖曳手勢＋`PaceChart`檢查站點擊
- `DeviceAuthPage.tsx` / `CliAuthPage.tsx`:CLI 登入核准頁的「核准」按鈕
