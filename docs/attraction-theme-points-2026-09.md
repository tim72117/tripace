# 景點主題點規劃（2026-09）

散策羅盤的「主題點/精選點」分級（`level === 1` 為主題點，其餘為精選點，
見 `useAttractionOverlays.ts`/`geoAttractionOverlay.ts` 的 `isTheme` 說明）
這次一併盤點各城市現有景點資料，決定哪些該升級/新建為主題點。這份文件
只記錄**決定**，尚未實際寫入資料庫——執行前需要先確認座標/半徑/精選點
素材，見文末「待補資料」。

## 主題點命名原則

主題點名稱要讓人一聽就能聯想周邊意象、直接猜到附近有什麼特色景物——
不是行政區名稱或純地標學名。例如「尼曼區」改成「尼曼文青咖啡巷」，
「清邁大學周邊」改成「清邁學生美食街」，都是同一個原則下的調整。
