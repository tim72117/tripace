## 1. 美術方向與情緒板

**一句話：** 一座漂在暮色海面上的小山城，天色從夕陽橘慢慢沉成藍紫，紅燈籠沿著石階一盞一盞亮起來——讓人看一眼就想上山、想截圖傳給朋友。

| 面向 | 方向 |
| --- | --- |
| 造型 | 低多邊形、平面著色、圓潤可愛但不幼稚；建築用最基本的方塊、三角柱屋頂、四角錐台屋簷組成，像玩具模型。 |
| 主色 | 燈籠紅 `#d63a2f`、暖黃光 `#ffc15a`、黑瓦 `#2e3440`、牆米白 `#efe2c8`、紅磚 `#a8553a`、石階灰 `#8d8a82`、木色 `#7a4b2e`。 |
| 環境色 | 夜空藍紫 `#2b2f5a`、山的深綠 `#2f5a3e`、海 `#2a4f78`。 |
| 色彩策略 | **冷背景、暖光點。** 天空、海、松樹、陰影一律往藍紫推；燈籠、窗戶、攤位是唯二的暖色（紅與黃）。夜晚畫面裡 80% 是冷色、20% 是暖光，燈火才會「跳出來」。 |
| 光線 | 傍晚是低角度、從鏡頭左後方（西北西）打來的長側光，屋頂邊緣鍍金；夜晚只剩微弱的藍色月光，主光源變成燈籠本身。 |
| 氛圍關鍵字 | 慢、暖、懷舊、「像從電影裡搬出來的場景」（文章結尾原句）、霧氣、熱湯蒸氣、貓。 |
| 截圖感 | 畫面有清楚的對角線（石階光帶從右下往左上爬到茶樓）、有前景（老街攤位）、有頂點（發光的茶樓）、有留白（海與天）。 |

情緒板文字描述（給要找參考圖的人）：
1. 豎崎路石階夜景：兩側紅燈籠成一條往上的光河，石階被映成暖橘色。
2. 阿妹茶樓正面：多層木樓、每層屋簷都掛滿燈籠，背景是深藍天空。
3. 從茶樓欄杆往下看：層層黑瓦屋頂、遠方海面最後一抹橘光。
4. 低多邊形島嶼作品（HEART 政策島那類）：漂浮小島、玩具感、柔和陰影、小人偶。
5. 吉卜力式的「晚飯時間的街」：燈一盞盞亮起的瞬間，天色還沒全黑。

## 2. 島的構成

### 2.1 座標與尺度
- 島中心 (0, 0)，+x 東、+z 南（朝鏡頭）、+y 上；島半徑約 33~37 格，厚 7 格，海面在 y = -3.5。
- 地勢**由南（低、海邊）往西北（高）**堆疊，鏡頭從南方看時，山城自然「往上、往後」展開，茶樓剛好在畫面左上的頂點。

### 2.2 階地

| 層 | 頂面高度 | 範圍（約） | 內容 |
| --- | --- | --- | --- |
| 地面 | 0 | 整個島體 | 南側前緣：第一站基山街、小吃攤、榕樹、海邊老屋 |
| T1 | 3 | 中心 (0,-5)、半徑 28×21 | 第一層住宅坡；南側中央切出 x 1~7 的缺口，豎崎路石階嵌在裡面 |
| T2 | 6 | 中心 (-2,-9)、半徑 24×13 | 石階頂端落在這層；第三站輕便路沿這層往西緩坡上行 |
| T3 | 7.5 | 中心 (-13,-10)、半徑 10×9 | 西北小高台，輕便路的終點 |
| T4 | 9.5 | 中心 (-15,-13)、半徑 6.5×5.5 | 最高層：阿妹茶樓與背後松林 |

各層輪廓是帶低頻雜訊的橢圓，**石階、坡道接上階地邊緣的角度設了「保護區」不加雜訊**，確保幾何剛好接合（已用腳本檢查：每層都完整包含在下一層之內，步道各點的地面高度與預期一致）。

### 2.5 步道與四站

| 站 | stopId | 位置 (x, z) / y | 模型 / scale / rotY | 示意時間 | 氛圍 |
| --- | --- | --- | --- | --- | --- |
| 壱 基山街 | stop_1 | (-6, 24) / 0 | stop-jishan-street / 16 / 0 | 17:30 | 熱鬧、蒸氣、店面先亮 |
| 弐 豎崎路石階 | stop_4 | (4, 10.6) / 0 | stop-shuqi-stairs / 14 / 0 | 18:30 | 燈籠一盞接一盞亮起（高潮） |
| 参 輕便路散步 | stop_5 | (-0.5, -4) / 6 | stop-qingbian-lane / 10 / π/2 | 19:30 | 安靜、只有路燈 |
| 肆 阿妹茶樓 | stop_6 | (-15, -14.6) / 9.5 | stop-amei-teahouse / 7 / 0 | 20:15 | 終點、俯瞰、全亮 |

步道寬 2.2 格，從島西南的入口沿基山街往東 → 北轉上石階（爬升 6）→ T2 上往西轉進輕便路（緩坡 +1.5）→ 小石階（+2）→ 茶樓前。`layout.ts` 另外匯出 `PATH_POINT_Y`（每個步道點的腳底高度），旅人走石階時才會平順爬升。

### 2.6 散落物（程式計算，共約 130 筆）
放置順序就是優先順序：指定位置的燈籠串、小吃攤（+蒸氣）、貓、茶壺 → 沿步道的燈籠/路燈 → 沿階地等高線的屋舍（一半門前掛燈籠）→ 階地南緣的燈籠帶 → 島緣的樹（南側榕樹、北側松樹）與茶樓後松林 → 竹叢 → 第二排屋舍 → 崖腳灌木與岩石。
每筆都檢查：腳印在同一層平面上（不卡牆、不懸空）、與步道保持距離、不進站點腳印、不和其他物件重疊；`y` 一律取所在階地高度。

## 3. 各時段光影與燈籠亮起節奏

關鍵時刻（`layout.ts` 的 `lighting`），相鄰時刻線性插值：

| 時刻 | 天色 | 太陽 / 月 | lanternGlow | 畫面重點 |
| --- | --- | --- | --- | --- |
| 06:00 | 粉藍漸層 | 東方低角度暖光 | 0.30 | 從深夜回到白天的過渡，燈籠還沒熄完 |
| 12:00 | 晴朗天藍 | 正南高角度白光 | 0 | 白天的玩具山城：黑瓦、白牆、紅磚對比最清楚 |
| 16:00 | 淡藍偏暖 | 西方 28° 暖黃 | 0 | 影子開始拉長 |
| **17:30** | 上藍紫、下暖橘 | 西北西 7° 橘光 | 0.12 | 整座島鍍金；只有店面、攤位暖光先亮 |
| 18:00 | 最紅的晚霞 | 1°、即將落下 | 0.32 | 燈籠開始點亮，零星幾盞 |
| **18:30** | 藍調時刻：深藍天、粉橘地平線 | 落下（-2°） | 0.62 | 燈籠快速點亮，石階變成光河 |
| 19:00 | 藍紫 | 月光（偏藍、弱） | 0.85 | 大部分亮起 |
| **19:30** | 藍紫夜 | 月光 | 0.96 | 紅與藍紫對比最強——**封面時刻** |
| 20:15 | 深藍 | 月光 | 1.00 | 茶樓時刻，全亮 |
| 21:30 | 深夜藍 | 月光 | 1.00 | — |
| 22:00 | 最深 | 月光 | 0.90 | 店家打烊，燈火稍稍收斂；接回 06:00 |

**「一盞一盞亮起」的實作建議**（渲染層）：`lanternGlow` 是全島的總進度，不要讓所有燈同時從 0 漸變到 1。每個 emissive 物件依它的 `seed`（或在島上的位置）分到一個門檻 `t ∈ [0, 0.8]`，該物件的亮度 = `smoothstep(t, t + 0.12, lanternGlow)`。門檻的分配建議：
- 店面、攤位、窗戶：門檻偏低（0~0.25），傍晚最先亮——生活感。
- 豎崎路石階的燈籠：**由下往上**依 z 分配門檻（0.25~0.55），18:30 旅人到站時正好看到燈從腳邊往上一路點亮。
- 其他燈籠：0.3~0.8 隨機。
- 路燈：統一 0.45，輕便路那段整排同時亮（和燈籠的錯落形成對比）。

## 4. 鏡頭設計

所有座標為世界座標（格）。建議 FOV 35°（小島的玩具感靠窄 FOV 壓縮透視）。

### 4.1 預設視角
- 位置 (26, 30, 54)，看向 (-3, 4, 0)。從東南偏南、約 30° 俯角看整座島：前景基山街、中段石階光帶、左上角茶樓、四周海面都在畫面內。

### 4.2 可環繞範圍
- 水平方位：以正南為中心 ±75°（北側背面裝飾較少，不開放繞到背後）。
- 俯角：20°~65°；距離 30~95。
- 目標點限制在 x -20~15、z -15~25、y 0~8 的盒子內，避免把島拖出畫面。

### 4.3 導覽時每站的鏡頭停靠點

| 站 | 鏡頭位置 → 目標 | 運鏡 |
| --- | --- | --- |
| 開場 | (40, 45, 75) → (-3, 3, 0) | 從遠處慢慢推近到預設視角（3 秒），天色同時從 16:00 推到 17:30 |
| 壱 基山街 | (10, 8, 40) → (-6, 1.5, 24) | 低角度沿著街從東往西看，攤位蒸氣在前景；鏡頭跟著旅人緩慢側移 |
| 弐 豎崎路石階 | (4, 3.5, 32) → (4, 6, 4) | **經典仰角**：站在石階下方往上看，兩側燈籠由下往上亮起；旅人爬階時鏡頭緩慢上升跟拍 |
| 参 輕便路 | (10, 13, 8) → (-1, 7, -4) | 側面平移，路燈在畫面上排成一列；運鏡放慢（呼應「心情沉澱」） |
| 肆 阿妹茶樓 | (-22, 17, -24) → (2, 2, 22) | **越肩俯瞰**：從茶樓背後高處越過屋頂看整座山城的燈火與遠方海面；停留後拉遠回到封面視角 |
| 結尾 | 封面視角 | 出現署名與「用 Tripace 排我的九份」按鈕 |

### 4.4 封面視角（截圖/錄影分享）
- 時間 19:30、位置 (30, 14, 40)，看向 (-4, 5, -2)，FOV 30°。
- 構圖：石階光帶從右下往左上形成對角線、茶樓位於左上三分點、前景基山街攤位的暖光與蒸氣、右上角留一片藍紫天空給標題字。
- 直式版本（9:16，限動/短影音）：位置 (14, 20, 46)，看向 (-4, 4, 0)，讓島剛好佔畫面中段 60%。
- 錄影建議：從 17:30 到 19:30 的縮時（約 8 秒），鏡頭在封面視角附近做 15° 的緩慢環繞。

## 5. 特效清單

| 特效 | 建議做法 | 手機成本 |
| --- | --- | --- |
| 燈籠光暈 | 桌機：選擇性 Bloom（只對 emissive 圖層），強度隨 `lanternGlow`。手機：每盞燈籠放一張加法混合的柔光貼圖 Sprite（billboard），大小約燈籠 3 倍，不用後製。 | Bloom 高；Sprite 低（130 盞約 130 個 quad，可用 InstancedMesh） |
| 燈籠/窗戶「點亮」 | 見第 3 節的門檻機制；亮起瞬間 emissiveIntensity 小小過衝（1.2 倍再回落）會很有生命感。 | 低 |
| 夜晚的燈籠點光 | 不要每盞都用 PointLight。只放 4~6 盞（每站一盞＋茶樓兩盞）真正的 PointLight，其餘靠 emissive + 光暈假裝。 | 中（燈數固定） |
| 蒸氣 | 模型本身已有 sway；可再加 2~3 顆緩慢上升、縮放、淡出的球（需要透明度，見契約建議）。 | 低 |
| 霧 | `scene.fog` 用 FogExp2，顏色取 `lighting.fog`；傍晚濃度略高讓遠處海面柔化，夜晚降低。九份的山嵐感也可以在島邊緣放 2~3 片低透明度的大平面雲帶。 | 低 |
| 海面夜晚反光 | 海面用低粗糙度材質；在每站正下方的海面放垂直拉長的加法 Sprite 當「燈火倒影」，隨時間微微抖動。不建議用即時反射。 | 低 |
| 螢火蟲 | 輕便路與竹叢附近 20~30 個 Points，暖黃綠、緩慢漂浮、19:00 後出現。比天燈更符合「安靜小路」的氛圍。 | 低 |
| 天燈（選配） | 天燈是平溪的意象，不是九份；若要用，建議只在結尾 CTA 出現時從茶樓飄起 1~3 盞，當作「點一盞燈火」（文章標題）的隱喻。 | 低 |
| 貓 | 目前是坐姿模型（尾巴與頭有 sway）。可加「貓偶爾換位置」：在附近 2~3 個預設點之間淡出淡入，或日後做走路版模型。 | 低 |
| 旅人的影子 | 太陽光開陰影即可；夜晚改用旅人腳下一張圓形暗色貼圖（blob shadow），比月光陰影穩定。 | 低 |

## 6. 島上標籤與資訊卡

### 6.1 站點標籤（3D 場景內，HTML overlay）
- 形狀：米白紙質圓角膠囊 `#efe2c8`，左側一枚紅色印章圓（`#d63a2f` 底、白字）寫站序「壱／弐／参／肆」，右側站名，再右側小字時間 `17:30`。
- 夜晚時標籤底色不變（紙燈籠的感覺），外加一圈淡淡的暖黃外光。
- 標籤掛在站點模型上方，以一條細線連到地面；旅人到站時標籤輕微放大並彈跳一次。

### 6.2 資訊卡（點建築後）
- 卡片頭：大字站名 + 印章站序 + emoji + 時間；副標用 `blurb`。
- 內文：文章該站的 `desc`（必要時截斷 + 「看全文」）、文章圖片（`media`）橫向滑動。

## 7. 契約建議

以下是目前契約不夠用、我在 `layout.ts` 先用替代方案處理的地方，請評估是否納入 `layoutTypes.ts`：

1. **步道高度**：`path.points` 只有 (x, z)，旅人在石階上無法平順爬升。建議 `path` 增加 `y?: number[]`（與 points 一一對應），或允許 `Pt` 為 `[x, z, y?]`。目前 `layout.ts` 另外匯出 `PATH_POINT_Y` 作為過渡。
2. **太陽方位角約定**：`sunAzimuthDeg` 沒有定義 0° 的方向。`layout.ts` 採用 0° = 北（-z）、90° = 東（+x）、180° = 南（+z）、270° = 西（-x），請寫進契約註解。
3. **燈火逐盞點亮**：建議契約註明 `lanternGlow` 是「全島進度」，渲染層依 `Placement.seed` 分配門檻（第 3 節）。另外 `model.ts` 的材質快取以顏色為 key 共用，若要逐盞點亮，需要對 emissive 材質做每實例複製或改用 InstancedMesh 的實例顏色。可選：`Placement.glowOrder?: number`（0~1）讓版面手動指定順序（例如石階由下往上）。
4. **河流可為空**：本島 `river.points = []`（九份沒有顯著河流），請讓渲染層對空陣列直接略過，並在契約註明「可為空」。
5. **階地側壁顏色**：階地擠出後的側面（擋土牆）建議可指定 `sideColor`（建議石牆灰 `#8d8a82`），否則側面若用草色會像蛋糕。
6. **站點鏡頭**：建議 `StopAnchor` 增加 `camera?: { position: [x, y, z]; target: [x, y, z] }`，第 4.3 節的停靠點就能直接寫進版面資料。
7. **文章署名**：建議 `IslandLayout` 增加 `meta?: { title: string; author: string; sourceSlug: string; eyebrow?: string; ctaLabel?: string }`，讓標籤、資訊卡、分享截圖都從版面讀取署名。
8. **透明度**：`Part` 沒有 opacity，蒸氣、霧帶只能做不透明。建議 `Part.opacity?: number`（`transparent: true`、`depthWrite: false`）。
9. **散落物高度偏移**：蒸氣需要放在攤位上方，目前直接把攤位上緣高度加進 `Placement.y`；若渲染層會把 `y` 當作「貼地」做對齊，請改為新增 `yOffset`。
10. **地表高度查詢**：`layout.ts` 匯出了 `groundY(x, z)`（取包含該點的最高階地），渲染層讓旅人、標籤貼地時可直接用。
